Monitors the full AI and Securing AI landscape — tracking model releases, agentic systems, security incidents, compliance changes, framework updates, and startup activity using a local LLM. No cloud, no external APIs.

## Research Domains

- **AI Models** — Releases, benchmarks, jailbreaks, and buzz across GPT, Claude, Gemini, Llama, and the open-source ecosystem
- **Agentic AI** — Autonomous agents, multi-agent systems, open-source projects, community debates
- **Agent Ecosystems** — MCP, A2A protocols, agent marketplaces, interoperability standards
- **AI Frameworks** — LangGraph, AutoGen, Azure AI Foundry, AWS Bedrock, CrewAI, N8N and more
- **Agentic Security Products** — Startup launches, funding rounds, runtime protection tools
- **AI Security Incidents** — CVEs, prompt injection, agent compromises, red-team findings
- **AI Compliance & Regulation** — EU AI Act, NIST AI RMF, OWASP LLM Top 10, ISO 42001
- **AI Governance & Trust** — Responsible AI frameworks, transparency standards, human oversight
- **AI Security Landscape** — Trust control layers, posture management, governance platforms

## Dashboard Capabilities

- **Run Full Research** — trigger a research run across all 9 domains on demand
- **Ask All Reports** — ask any question across all saved reports (RAG over last 5 reports)
- **Per-Report Chat** — open any report and ask questions scoped to that report only
- **Live Topic Research** — ad-hoc web research on any AI security topic
- **Schedule Management** — set daily, weekly, or monthly automated runs from Settings

## Customising Topics

Open ⚙️ Settings → Topics to edit the research queries for any domain. Changes take effect on the next run — no rebuild required.
